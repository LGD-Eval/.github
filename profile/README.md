## 读我们的东西前，请先看三条口径

1. **数字都带分母。** `0.9688` 只指 pccp-bench 0.1.3 自身的 32 道公开题、且是我方参考实现的成绩，不可外推；空基线是 0.351（37 题口径）。
2. **分类分歧不藏。** 引擎的"否决"与我方的"另交"是两套读法，已命名并版本化：`DIVERGENCE / criterion-axis / v1`，影响面与解除条件都写在文件里。
3. **没过门的事写明没过。** 外部 AI 复核两轮判"错案库不可公开"，我们照原样挂着，不改成"已通过"。

## 两条我们不承诺的事

- **不承诺回复 issue。** 没有专职工位，承诺了就是欠债。
- **不自称权威或官方。** 这里没有任何监管机构的背书；PCCP 是 FDA 的法定术语，我们只做评测，不做认定。
